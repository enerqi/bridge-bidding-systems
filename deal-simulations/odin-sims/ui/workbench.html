These are the notes themselves - the .bml chapters this whole repository is written in, the ones that build into the html system documents. Edit one here and press preview to see the rendered page beside it, without saving and without a build. The preview parses the text in the editor, so it shows what you have typed rather than what is on disk, and once it is open it is LIVE: it re-renders itself when the typing stops. It waits longer on a document that is expensive to render (the assembled system takes about a second), and WORKBENCH_LIVE_MS sets that wait - 0 turns it off and leaves preview as the only thing that renders. save writes the file. preview is a toggle: pressing it again closes the panel, which also hands back what the rendered page was holding. fold collapses the document to its headings, leaving the section the caret is in open and the other bodies as an ellipsis, so the whole outline is still there to navigate by. A small chapter opens unfolded and a big one starts folded (the assembled system costs a few hundred MB rendered in full); whichever way you leave it is remembered for that file. CTRL+R opens the heading palette: type part of a heading's name and the caret jumps there, in this file or any other chapter in the folder (the letters only have to be in order, so lbn finds Lebensohl). Spaces and punctuation are separators, not characters, so 1h 1s finds 1H-1S, 1H--1S and 1H/1S alike — you never have to type the dashes. It is how to get about a 1000-heading corpus without scrolling: up/down choose, enter jumps the caret there (and scrolls the preview to the same heading), esc closes. Anything the parser objects to is underlined in the source as well as written to the transcript below - hover a squiggle to read it. A red one means something is being DROPPED from the page (a misspelled directive, an #INCLUDE that cannot be read); a yellow one is a warning. Press links to check cross-references too: that one is off by default because a chapter links to headings in its sibling chapters on purpose, so it only tells the truth on a whole document.
