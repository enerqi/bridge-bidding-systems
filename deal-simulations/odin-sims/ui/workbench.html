The deal generator and the single-deal advisor of this bidding-system repository, in one window.
Every keyboard shortcut - zoom, moving between views, the hand page, the scenario list - is listed by CTRL+/. Hover over any control for what it does; the bar at the bottom says more.

preview

The .bml chapters these notes are written in: edit one, see it rendered, save it.

  • preview shows the rendered page beside the text, and keeps up as you type (it re-renders when you pause). Press it again to close it.
  • save writes the file.
  • fold collapses the chapter to its headings, keeping the caret's section open. Remembered per file.
  • CTRL+R jumps to any heading in any chapter. The letters only need to be in order (lbn finds Lebensohl), and dashes don't matter (1h 1s finds 1H-1S).
  • Squiggles are problems the parser found — hover one to read it. Red means something will be missing from the page; yellow is a warning.
  • links also checks cross-references. It is off by default because a chapter links to its sibling chapters, so it only gives a true answer on a whole document.
